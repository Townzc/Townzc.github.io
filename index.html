GASP-SAM: Lightweight Geometry-Aware Semantic Prompting for Abdominal Organ Segmentation

Project Leader

A two-stage SAM adaptation framework for box-prompted abdominal multi-organ CT segmentation, designed to reduce domain shift, add organ-specific semantics to spatial prompts, and correct local boundary errors without disrupting reliable coarse predictions.

  • Adapted SAM ViT-B with LoRA while keeping the SAM prompt encoder and BioMedCLIP text encoder frozen, reaching strong medical-domain transfer with only 8.10M trainable parameters.
  • Designed organ-aware semantic prompt learning and TextCIM cross-modal interaction to inject anatomical identity into dense SAM image features.
  • Introduced geometry-guided residual fusion with boundary, center, and signed-distance cues so structural priors remain active during inference.
  • Built a prior-guided local residual refiner that trains only 0.72M parameters and updates compact ROIs while preserving coarse logits outside the refinement region.

LiftCut Tracker: AI-Powered Fitness and Fat-Loss Tracking Platform

Full-Stack Developer · Next.js 16, TypeScript, Supabase, DeepSeek API

Built and deployed a clean, ad-free fitness tracking web application that combines training plans, workout logs, nutrition records, body metrics, and AI-generated coaching workflows. The project was designed as a real product rather than a static demo, with authenticated user data, server-side AI APIs, persistent database storage, and a guest-to-account migration path.

  • Implemented a Next.js App Router architecture with TypeScript, Tailwind CSS, shadcn/ui, Zustand, Zod validation, next-intl localization, Recharts dashboards, and PDF export through jsPDF.
  • Deployed server-side AI API routes for training-plan generation, nutrition-plan generation, plan saving, and AI history management, keeping the DeepSeek API key isolated in server-only environment variables.
  • Provisioned a Supabase backend with Auth, Postgres, Storage, row-level security policies, relational training/nutrition schemas, indexed user timelines, and an avatars bucket for profile media.
  • Designed a structured AI workflow: user profile and constraints are validated, DeepSeek returns schema-checked JSON, users preview and edit the result, and only confirmed plans are persisted.
  • Built guest mode with localStorage persistence, daily AI quota control, and one-click migration of training plans, workout logs, food logs, body metrics, and AI history into a formal account.
